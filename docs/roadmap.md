# Delivery roadmap

## Milestone 1 — working foundation

- Monorepo, web, API, extension, database, shared contracts, and local infrastructure.
- Landing page and a small translation playground.
- Health checks and adapter interfaces for N-ATLAS.

## Milestone 2 — usable product

- Password sign-up with Brevo email-code verification and password sign-in.
- Organizations, projects, API keys, usage tracking, and a dashboard.
- Glossary, translation memory, language rules, and brand voice.
- Asynchronous translation jobs with progress updates.
- Complete the marketing routes: product, pricing, docs, blog, careers, contact, and privacy.

## Milestone 3 — browser and voice

- Safe DOM extraction and batch translation in the extension.
- Restore-original and language-switch actions.
- N-ATLAS speech recognition and accessible read-aloud controls.
- Route text-to-speech by language through reviewed Nigerian voices; never silently fall back to a generic browser accent.
- Low-bandwidth mode and clear consent/privacy controls.

## Milestone 4 — trust and growth

- Automated quality scorecards with plain-language explanations.
- Native-speaker review and approval workflows.
- Paystack subscriptions in naira.
- Developer API, Python SDK, JavaScript SDK, CLI, webhooks, and Git integration.
- Validation evidence: external testers, real interactions, and measured translation quality.

## NAIC submission path

- Submit under Problem Statement 1: Developer Infrastructure.
- Keep the voice layer as supporting differentiation and a future Problem Statement 2 track.
- Track the evidence checklist in `docs/naic-scope.md`.
